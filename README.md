# 奶豪鉴定所 · 奶蛙奶量鉴定

> 互联网抽象行为鉴定中心。打开摄像头，跟着奶蛙做 15 秒，本地算法比对动作与节奏，
> 生成你的「奶家人值」和专属称号：**奶王 / 奶后 / 奶家人 / 奶狗 / 奶使**。

纯静态网页，无需安装依赖、无需构建：打开 `index.html` 所在目录的静态托管即可运行，不需要后端。
摄像头画面只在浏览器内存里采样比对，不上传任何服务器；成绩只存在本机 localStorage。

## 打开方式

直接访问 GitHub Pages 地址即可（手机 / 电脑浏览器）。

> ⚠️ 摄像头功能要求 **HTTPS** 安全上下文（GitHub Pages 已是 HTTPS）。
> 微信内置浏览器对摄像头支持不稳定；如果页面里点「打开摄像头」没反应，
> 请点右上角「…」→「在浏览器打开」，或直接用手机系统浏览器 / 扫码打开。

不方便开镜头时，页面提供「从相册选视频」的备用入口。

## 目录

- `index.html` 单页入口
- `css/` 样式
- `js/` 应用逻辑（`js/config.js` 是文案与分档线配置）
- `material/` 图片、动作参考与示范视频

## 2026-10-31：姿势卡可以直接测试

五张姿势卡和“本轮挑战”下拉框均可选择。静态姿势倒计时后保持 5 秒，按上半身手臂/手腕关键点匹配；捧腹大笑和自选连续示范仍保留 15 秒动作比对。相册视频至少 3 秒。
